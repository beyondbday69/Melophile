## Material platforms

The Material Compose library is built in-house, so it receives the latest Material updates first. It’s the recommended platform for developing on Android.


![Material Design 3 Illustration](https://firebasestorage.googleapis.com/v0/b/design-spec/o/projects%2Fm3%2Fimages%2Fmpmhexvj-develop2.png?alt=media&token=81071026-a0eb-40e8-949c-cf13d8d89778)
*Jetpack Compose is the recommended toolkit for building Material UI on Android. Get developer documentation, tutorials, and feature highlights to build with Material for Android using Jetpack Compose.*


🔗 Reference: [https://m3.material.io/develop/android/jetpack-compose](https://m3.material.io/develop/android/jetpack-compose)

The Material Flutter library is actively maintained by the Flutter team and receives periodic Material updates.


![Material Design 3 Illustration](https://firebasestorage.googleapis.com/v0/b/design-spec/o/projects%2Fm3%2Fimages%2Fmrvexifk-mpmioepf-develop4.png?alt=media&token=b5517386-3c9a-4df9-be4b-854c4decded3)
*Flutter offers the best Material support for multi-platform app development. Get developer documentation to build with Material for Flutter.*


🔗 Reference: [https://m3.material.io/develop/flutter](https://m3.material.io/develop/flutter)
